# FC 中国象棋 · 界面操作原型

本轮按用户要求先做简单 HTML 设计预览，不进入 Lua、模拟器或完整游戏制作。2026-10-22 按用户确认改为现代点击，并按显示尺寸及设备像素密度进行高清绘制；保留 FC 构图、配色与固定头像。完整棋规/自将判定、真正 AI、将死/和棋、正式计时尚未实现；电脑仅按演示逻辑回棋。

## 打开

在项目根目录运行 `npm run preview:html`，打开终端显示的本地地址。也可直接打开 `prototype/index.html`；不依赖外网或额外包。

## 操作

- 游戏仅包含中间画布，外围网页标题、原型标签、装饰外框、工具栏与说明不属于游戏。本原型已移除这些外围展示；浏览器留边只是保持比例的背景。
- 点击一个模式开始。点己方棋子选中，再点目标落子；再点同一棋子取消，点另一枚己方棋子切换。
- 菜单、右侧按钮、确认框、重开选项均可直接点击。棋子选中后稳定显示边框，不再闪烁消失。
- 自定义页点击己方非帅棋子，再点击替换棋种；右侧可直接点击全部改车、恢复初始、开始对局、返回。
- 对局右侧三个按钮为“悔棋 / 认输 / 模式选择”。点击模式选择、确认结束本局后回到三模式菜单，自定义模式从菜单进入；取消则继续当前局面。
- 没有画布外控制按钮；再点已选棋子可取消。不提供暂停功能、自动暂停或继续对局弹层。
- 辅助键盘输入仍可用：方向键、Z 确认、X/Esc 取消、Enter 在菜单/结算页开始、Shift 切换操作区；Enter 在对局中不会暂停，原型默认引导使用点击。
- 右上只显示当前走棋方“黑方 / 紅方”与手数。开局 `000手`；双方每次有效落子加一，玩家落子后为黑方 `001手`，电脑回棋后为红方 `002手`；非法操作不增加，悔棋恢复计数，重开清零。

现代点击与高清绘制已经用户确认；确认框、悔棋规则与临时数值仍是预览提案，不声称逐项复刻原版操作。

## 预览范围与临时值

- 困难和自定义使用相同的思考等待，原型暂定 12 秒；仅快速模式为 0.7 秒。这些临时数值不代表原版实测或真实棋力。
- 走子演示包含基本棋种行走、挡子与吃子限制，不含完整自将、困毙等规则；无法据此验证正式游戏规则。
- 悔棋演示撤回到上次玩家行动前，包括电脑已回的一步；认输后可再来一局。
- 对局中先通过模式选择返回菜单，再选择自定义。编辑保持标准开局位置和数量，帅锁定；这只是流程提案。
- 头像固定不动。时间栏 `03:00` 为构图占位，尚未开启正式倒计时。

## 交互检查清单（2026-10-22 按操作变更更新）

| 场景 | 动作 | 预期 |
|---|---|---|
| 开局 | 直接点击快速模式 | 标准 32 子；固定老头头像；右下三项文字操作。 |
| 点击映射 | 点击首路兵；缩放窗口后再点击 | 正确选中最近的交点，不受画布内部像素密度影响。 |
| 选子 | 点兵，再点前一格 | 棋子前进一步；先显示老头思考，再演示回棋。 |
| 取消 | 再点同一棋子 | 取消选中，不改变棋局。 |
| 悔棋 | 直接点击悔棋 | 恢复玩家行动前的演示局面；无迟到回棋。 |
| 模式选择 | 点击右侧第三项，再选择否/是 | 否保留局面；是进入三模式菜单，从中可选自定义。 |
| 自定义 | 进入编辑，全部改车 | 己方为 1 帅 + 15 车；黑方与位置不变。 |
| 失败与重开 | 认输，确认，再来一局 | 认输反馈，头像不变；恢复该局初始配置。 |
| 无暂停 | 思考时按 Enter | 不出现暂停或继续弹层，等待到期正常回棋。 |
| 手数 | 开局、玩家有效落子、电脑回棋、非法走子、悔棋、重开 | 依次检查 000 / 001 / 002；非法操作不变，悔棋恢复，重开清零。 |
| 布局 | 桌面、手机横/竖屏 | 棋盘等比完整显示；控制键可操作。 |
| 高清绘制 | 查看画布宽高与显示尺寸、DPR；检查文字和棋线 | 内部宽高约为显示宽高乘 DPR；不先绘为 256×224 位图再放大。 |

这些是原型体验检查，不替代步骤 2 的正式游戏用例或步骤 5 的 Lua TDD。

## 千星迁移边界

- must-reproduce：FC 构图与配色、固定头像、三个模式、三个右下按钮、现代点击与清楚的选中反馈。
- excluded：画布外围标题、标签、外框、工具栏、手柄及说明；不作为正式游戏内容。
- can-degrade：辅助键盘焦点符号。
- concept-only：Canvas、浏览器输入、演示回棋与临时时间、网页字体及确认框提案。
- HTML 原点在左上且 Y 向下；千星原点在左下且 Y 向上，迁移需重新布局，不能复制 Canvas 坐标。
