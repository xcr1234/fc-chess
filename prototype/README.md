# FC 中国象棋 · 娱乐对战原型

用户已认可画面与点击操作。本轮仅同步最新规则和反馈，保留游戏画布范围、构图、配色和固定老头头像。正式Lua/Alpha-beta引擎、素材和真机尚未实现。

## 打开与检查

项目根目录运行`npm run preview:html`，打开终端地址；也可直接打开index.html。程序与参考图均在项目内。`npm run test:prototype`为Node定向回归，不是模拟器测试。

## 当前已实现

- 点击己方子选中、再点目标落子；同子取消、异子切换。稳定选框、高清棋线/棋字与缩放后的坐标映射保持原样。
- 困难/快速/自定义统一演示选招；快速算完立即走，困难/自定义算完后根据候选数和战术性附加等待。初始范围4..16秒，可调；不再固定12秒/0.7秒。
- 只计步时：当前行棋方从00:00增加，落子停住，下一次轮到该方重新清零；另一方保留上一步时间。无局时、倒计时判负或关卡。
- 自定义保留帅，其他15子可改；红士不限宫、红相可过河且受塞象眼限制，黑方与帅保留基本区域限制。草稿本次会话保留，重开用本局初始阵容。
- 吃掉将/帅才结束；可以不应将、送将、有机会吃将时改走其他子，不做将死/困毙或重复/长将裁判。照面不提前结束，同列无子可飞将吃对方将帅。
- 仍检查棋种几何、棋盘边界、挡子、马腿、象眼、炮架与己方占位。
- 悔棋先显示“要悔棋嗎？”及“是/否”，默认选“否”；选“是”撤回上次玩家行动（未回棋撤红一步，已回棋撤双方），清除旧等待并恢复手数，红方新步时清零。无可撤步直接提示。
- 认输/模式选择有是/否确认，默认否；确认期间步时和等待继续，到期回棋暂存，取消后提交一次。无暂停、无画布外控制按钮。
- 实际吃将/认输后显示结果、再来一局/模式选择；无下一关。极端无基本走法时跳过该方，双方都不能走则显示无法继续，不计胜负/和棋。
- 右上仍只有当前方、手数和头像。有效落子双方各计一手，开局000、悔棋恢复、重开清零。

## 验证边界

演示AI只有单层吃子优先选择，不是正式Alpha-beta、开局库或原版困难棋力。等待摘要使用B/T两项，不伪造完整迭代分差或不稳定度；正式AI接入后才加入可用的A/U项。HTML高分辨率Canvas、浏览器时钟和输入不是千星API或性能证据。

方向键/Z确认/X或Esc取消/Shift切换操作区保留为辅助。Enter不暂停。浏览器可见性恢复按实际经过时间推进；不能据此承诺千星后台计时。
