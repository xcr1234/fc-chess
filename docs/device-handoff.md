1. 在奇域编辑器导入`fc-chess.gia`。把导入的界面用于当前关卡的界面布局，确保「客户端控件容器」激活且可见；其中应有`FCChessHost`。界面由Lua动态创建，不需要再导入头像PNG或手工创建棋盘。
2. 核对四个客户端模板的实际索引：

   | FC_image | 1073741848 |
   | FC_textbox | 1073741849 |
   | FC_cursor | 1073741850 |

   以上为2026-10-24用户回传的真机实际索引，已同步源码与工程存档。客户端控件容器实际索引1073741845，FCChessHost实际索引1073741854，两者不用于Lua模板实例化。再次导入如发生索引变化，由源码`src/ui/primitives.lua`校准再打包；不要只手改产物。
3. 打开客户端脚本资源管理器，检查唯一入口`dist/main.lua`（本包文件名为`main.lua`），关联到本次解压的`main.lua`。已有正确映射时复用。检查脚本挂在`FCChessHost`容器节点上，不要挂到四个基础模板上，也不要重复挂载。整合包模拟器回读已保留映射/挂载，但真实编辑器仍要核对。
4. 保存关卡并重新试玩。日志应出现`Build date (local): 2026-10-24 19:41:52.480 +08:00`及`[fc-chess][ready] UI ready test=false`。只复制文件、导入GIA或保存映射，都不等于已经加载本轮脚本。
