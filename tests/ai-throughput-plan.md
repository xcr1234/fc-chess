# 出库与晚期送子反馈

2026-10-24 用户试玩快速模式后反馈棋力远不如JS小巫师，进一步明确“后期会送子”。不把现有规则/状态测试通过等同棋力通过；当前未取得用户所指晚期失误的完整棋谱，新增测试属于针对同类问题的防线，不能冒称已重现那一步。

步骤2→5→6：保持自定义娱乐设置，先减掉完整搜索的多余工作，再在相同预算验证完整迭代、晚期战术及JS对照。棋子动态索引实验未取得稳定深度收益，当前采用不新增可变索引的颜色快速过滤和合并增量更新。

用户最后更正为“保证速度”，覆盖此前短暂选择的“可接受更久计算”。标准计算上限继续4秒、每步128操作/32新节点及约3ms协作保护，自定义继续1.5秒浅搜，附加等待设置均不改；本轮不提高预算。

| 检查 | 操作与预期 |
|---|---|
| 增量状态 | 合并移子哈希/评价后，吃子、将帅移动、空步/跳过及撤销正确；自由阵容无固定数量限制 |
| 搜索完整性 | 快速过滤生成的全部/吃子走法与穷举基本几何一致，固定深度根分/最优着集合与原路径一致 |
| 优先着法 | 对同一局面开/关延迟生成，固定深度根分相同，根候选不重复；实际在优先着法失败高分时跳过生成/排序其余走法 |
| 路径语义 | 标准离线档保留重复历史身份；生产无重复评分，不维护无用的整条路径身份，但区分连续pass/null的叶子环境 |
| 晚期基本战术 | 不漏吃无保护重子，受到车马炮兵单一攻击时保护重子，仍允许正确交换、弃子和优先吃将 |
| 相同资源比较 | 原提交与候选在相同局面、规则、工作量/时间和冷缓存下对照，记录深度、节点、实际时间；不只加大配置深度 |
| 完整接入 | 同次产物同步两份存档，规则、取消/悔棋、模式/等待和模拟器回归；不通过延长计算或等待改善棋力 |

真实试玩残局仍需要保留局面才能精确复现。正式400局和真机验收继续未完成；此次结果只报告取得的局部证据。

## 已执行结果

4组路径/走法/优先着法检查、24组捉子回归通过；晚期马/车/炮断言跟踪移动后落点，采用游戏几何判断可信回吃与等值补偿。完整12套件/129条Lua PASS组、67项模拟器用例（264断言）、工具28/28通过。16局短时限JS对照2胜11负3和、得分21.875%，没有证明棋力提高。详见[报告](../docs/ai-throughput-results.md)，不把策略Red当作用户送子原局已复现。
