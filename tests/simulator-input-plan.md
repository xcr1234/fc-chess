# 模拟器点击响应回归（2026-10-24）

用户反馈：模拟器预览中选子、落点和悔棋不灵敏，怀疑只有中心可点。本轮窄修复步骤2→5→6，只处理预览输入，不改变棋规。

源码证据：Square 热区为16×16、交点间距16，棋子15×15；棋盘热区无缝。0.4.1运行时在按下后出现任何坐标变化即开始拖拽，抬起时不再产生CursorClick。浏览器移动事件有60ms合并，普通轻点也可能带入小幅移动。

| 需求 | 操作与预期 | 证据 |
|---|---|---|
| 轻点容忍自然抖动 | 按下→累计位移不足5 CSS px→抬起，仍选子/落子/悔棋；每次只执行一次 | 真实createPlaySession绑定事件流，回放到原生Worker，五画布 |
| 整块棋格可点 | 各路棋子热区边缘点选、落到相邻空格边缘，不能只测中心 | 五画布原生坐标用例 |
| 保留拖拽 | 达到5 CSS px后仍发move；累计慢移/移出再回来仍为拖拽 | 真实绑定事件流测试 |
| 设备独立 | 阈值按屏幕CSS距离，不随画布分辨率/等比留边变化 | 五画布及不同显示比例 |
| 生命周期与取消 | cancel/lostcapture/重启后下一次轻点正常；第二触点不串入当前手势 | 真实绑定事件流测试 |
| 可重复安装 | 补丁重复应用相同，能还原固定版本，拒绝未知上游代码 | 版本/哈希及既有高清文字回归 |

轻点必须在原控件内抬起；移到相邻棋格/按钮不会误触原控件。原生runCase的单个pointer click不包含按下期间的move，原有测试无法覆盖本问题。上述阈值是预览修正策略，不当作官方或真机语义。
