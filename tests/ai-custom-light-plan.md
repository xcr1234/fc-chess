# 自定义娱乐搜索调整

用户于 2026-10-24 明确：自定义是娱乐模式，不要求复杂计算。此约定覆盖此前“三模式相同计算预算”的自定义部分；困难与快速仍同预算、同棋力，棋规和附加等待策略不变。

## 行为与用例

| 需求 | 操作与预期 | 证据入口 |
|---|---|---|
| 15 车不困在长串静态搜索 | 红方全部改车并走 55→46；黑方在确定性 30/60 FPS 调度下至少完成一轮候选比较，输入/工作状态完整恢复 | `lua-ai-custom-light.lua`、宿主采样 |
| 有限计算 | 自定义默认最多 2 层、无静态延伸/将军延伸，1.5 秒逻辑截止、2000 节点上限；保留分帧配额及墙钟片段保护 | 配置/截止用例 |
| 基本战术 | 能吃敌将时立即吃；面对红方自由士相攻击时选择不被立即吃将的走法；能够吃掉无保护重子 | 手写稀疏棋盘 |
| 危险叶子不会拖垮首轮 | 有限层数到达时使用明确的娱乐静态估计，不继续应将树，也不将估计混入完整战术搜索的 TT 值 | 危险边界/缓存隔离用例 |
| 全部自定义都生效 | 标准外观阵容仍使用娱乐策略，自定义仍禁书；取消、悔棋和过期任务保持正确 | 会话与模拟器用例 |
| 标准棋力不变 | 困难/快速默认预算、静态搜索、危险边界中止及固定 JS 对照不变 | 原回归与核心对照 |

先执行上述用例取得真实 Red，再实现并回归。宿主数据记录初始化/step、完成深度和保底；不把逻辑时间或 Fengari 耗时当成真机性能。三类阵容持续对局及模拟器回归使用同次打包、同步保存的产物。本次不重跑标准短时限棋力赛，不宣称提升标准棋力。

## 结果

Red为3/9，Green为9/9。32次宿主采样及86半回合持续对局没有首轮保底；原回归11/11套件、模拟器67/67（264断言）通过。详见[结果与证据](../docs/ai-custom-light-results.md)；真机与复杂战术棋力不在本轮通过范围。
