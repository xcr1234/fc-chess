# 四字像素字接入

用户授权将已审阅的“包 / 俥 / 傌 / 將”试稿替换进游戏。属于素材接入，不制造人工行为Red。维护源为assets/pixel-font/glyphs-16.json；生成器把合并后的矩形重新栅格化，对照源格点检查漏格、额外格和重叠。

`npm run test:pixel:simulator`在正式存档、五种画布执行每项：

| 操作 | 预期 |
| --- | --- |
| 开快速局 | 初始7个目标棋子显示像素，原生同字隐藏，其余字原生；148个像素矩形 |
| 自定义打开棋种菜单 | 俥/傌显示像素，同名原生文字隐藏，其余棋种文字仍可见 |
| 用真实pointer走红傌 | 新格出现傌像素，旧格无残影，命中区可用，总笔画数不变 |
| 用真实pointer确认悔棋 | 红傌回原格、手数归零，目标空格无旧笔画 |
| 自定义兵改俥再改兵 | 像素组销毁，恢复可见原生兵，不留旧笔画 |
| 全部改俥后空闲重绘 | 15枚红俥，像素矩形386个；连续重绘不增加控件 |
| 恢复初始 | 恢复原生兵，像素矩形回148个 |

截图只含游戏画布；PC/手机棋盘、菜单和15俥共6张。UI模型与截图不证明真机性能；真机需保存重新试玩，检查字大小、边缘接缝、走子/悔棋/换字以及15俥流畅度。
