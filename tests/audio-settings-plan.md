# 标题页声音设置（2026-10-24）

用户最终要求：音效固定50882，可独立开关；BGM自由选曲/关闭，推荐前置标明；支持已核验能调节的音量。

| 契约 | 操作/预期 | 回归 |
|---|---|---|
| 入口和返回 | 标题画布内“设置”，设置/选曲返回不开始游戏，不触碰对局历史 | Lua会话、HTML、原生用例、五画布 |
| 独立配置 | 标题与对局各选一首或无BGM，音效开关独立；回菜单/开局/悔棋保留本次会话选择 | Lua会话、原生 |
| 完整目录 | 188条音乐，按用途将推荐前置并标记；分类/翻页可到全部曲目；无重复，拒绝未知/音效ID | Lua、数据静态检查 |
| 音量 | BGM 0–100%，默认30%，±10且钳制；0为静音，不清除已选曲 | Lua、原生 |
| 落子音效 | 固定50882；红/黑有效提交各一次，选子/非法/悔棋/刷新不播放，关闭后不补播旧事件 | 音频适配器mock、原生audio事件 |
| BGM信号 | 开局/切场景/改选择/改音量发送正确的音乐ID/百分比/时长；相同状态不逐帧重发；销毁请求关闭 | 适配器mock、模拟器服务端接收变量 |
| 接入边界 | 官方Lua仅有PlayAudio2D/StopAudio/IsAudioAlive，BGM走ServerSignal接官方服务端音乐节点；模拟器不具备原生BGM播放 | 官方文档和接线说明，不能把变量/信号PASS称为BGM听觉通过 |

设计：全屏画布内设置，标题/对局选曲分别进入分类分页列表，每页5首。标题推荐10167杯中明月、10161桃符春叙；对局推荐10029追寻仙迹、10167杯中明月。保持目录抄录名称，不把10033的OCR推断作为推荐。只在本次脚本生命周期内保留偏好，不承诺跨退出持久化。

声音配置是纯会话状态；平台副作用由audio.controller处理。serverLogic只把FCChessBGM信号参数记入模拟器PlayerSelf变量，属于接收探针，不能导出成真实BGM节点图。没有可用的真实节点图写入工具，真机需按docs/audio-integration.md连接信号与官方音乐节点。
