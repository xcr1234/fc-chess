# 现成开局库接入用例（2026-10-23）

范围：XQWLight自带书库的离线格式适配，不收集棋谱自建库。进入步骤5前制定以下用例；纯Lua新增用例先在旧实现执行Red，随后用本次构建产物执行模拟器回归。

| 需求/规则 | 前置与操作 | 可观察预期/独立oracle | 用例/证据 |
|---|---|---|---|
| 超过首回合的真实书库 | 标准局面走中炮，按源库候选继续红黑两次 | 首次和第二次黑方回复均命中，无搜索节点；候选来自固定上游文件 | lua-opening-book / multi-turn；原生模拟器书路用例 |
| 方向与棋盘一致 | 左右镜像首着，查双方候选 | 起止坐标正确镜像、权重不变，全部通过本项目基本走法检查 | lua-opening-book / mirror；JS转换校验 |
| 完整局面与规则隔离 | 改变棋盘、交换行棋方、启用自定义 | 不错误命中；未命中执行现有搜索，可中止并还原 | lua-opening-book / fallback；既有ai-custom-book |
| 加权且可复现 | 固定种子重复、再遍历多种种子 | 同条件同着法；不同种子可选不同候选；按权重区间选取 | lua-opening-book / seed；JS/Lua权重边界用例 |
| 允许送将规则下的书着安全 | 立即吃将、候选导致己将下一手可被吃 | 赢棋优先；危险候选退出书库，不改变玩家规则 | lua-opening-book / king；既有吃将回归 |
| 悔棋/等待不污染随机序列 | 困难模式算出书着、等待、提交、悔棋及重走 | 提交前种子不推进，提交后推进；悔棋恢复种子和同一应对，取消清旧结果 | lua-opening-book / undo；既有反馈/确认层回归 |
| 转换来源与覆盖可追溯 | 固定上游文件、再生成两次、核对所有导出记录 | 输出一致；完整局面索引、无非法候选；报告源条目/可恢复条目及未恢复量 | JS生成器与Lua全库验证；转换摘要 |

不把哈希命中当作完整局面身份；只导入可恢复并验证的现成记录。真实棋力及真机加载/内存属于后续设备验证，纯Lua/模拟器通过不替代真机结论。
