# 选中底色与走棋动画（2026-10-25）

用户要求：棋盘不显示选中/AI起落点方框；选中棋子底色加深；红黑双方棋子整体移动到落点。

1. 选子/换子/取消：仅当前棋子白底变深，字和蓝边保持；没有棋盘方框。
2. 短步、长步、马步：途中底图与字保持同一坐标，结束只在目标出现一枚棋子。
3. 吃子/吃将：被吃棋子保留到移动结束，随后消失；吃将完成后再显示结果。
4. 快速模式即时回棋：红、黑动画依次播放，不跳过红方动画。
5. 连点：动画中不接受棋盘选子/落子；右侧操作可用。
6. 动画中悔棋、离局、重开：取消旧动画，恢复正确棋盘，无残影；设置页返回显示当前棋局。
7. dt=0、跨帧、大dt：坐标不越界，队列完成，空闲不反复分配控件。
8. 五画布验证选中与动画帧，截图仅游戏画布；HTML与Lua交互一致。

移动速度和深底色属于本次实现选择，未有原版连续录像标定，不宣称逐帧复刻。
