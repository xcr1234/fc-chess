# 只处理胜利完成

只在玩家获胜时发送无参数FCChessWin。服务端一条固定链，不放参数/变量/分支，不结束关卡。

| 场景 | 通知预期 |
| --- | --- |
| 开局/未结束/失败/认输取消及确认/中性结束 | 0次，保持平台默认状态 |
| 吃黑将胜利 | FCChessWin一次，无参数 |
| 重绘/回看/悔棋/重开/返回标题/客户端重建 | 不发送或撤销 |
| 胜后再输或中性结束 | 不发送，保持先前胜利资格 |
| 信号未定义 | 不崩溃、不逐帧重试，下一次胜利可再尝试 |

Lua7项覆盖真实胜负、认输、声音消费独立、中性及缺信号容错；7项回看回归。PC/手机各10流程核对实际生命周期接收探针、通知次数及继续操作，报告victory-only-simulator.json。原生ESC默认未完成/胜后完成及玩家绑定仍须真实编辑器接线后验证，探针不冒充原生属性。
