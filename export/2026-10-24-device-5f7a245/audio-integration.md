# 声音接入与音量

标题/模式页右下角「設定」打开声音设置。标题和对局独立选曲/无BGM；188首按分类、每页5首显示，推荐曲排前并标记。BGM默认30%，加减每次10%，范围0–100%；0%静音但保留选曲。普通落子音效50882，将军的落子改用50888（轻_通用_03），两者共用走棋音效开关，默认开启。仅双方有效落子时播放；选子、非法操作、悔棋不播放。偏好保留到本次脚本结束，未接跨次存储。

## 已实现的客户端

`src/audio/settings.lua`维护纯状态，`src/audio/controller.lua`执行副作用。音效使用官方`game.PlayAudio2D(50882或50888)`，关闭时停止本脚本仍在播放的实例。该API没有音量参数，所以音效只有开关。BGM索引不能传给音效API。

将军只做声音反馈：有效落子后，落子方任一棋子能按当前基本走法吃到对将即触发，包含发现将军与连续将军；同一步仅响一次50888，不叠加50882。沿用车炮遮挡/马腿/兵方向/自定义红士相范围和将帅照面规则，不禁止送将或不应将。吃将已终局时播放普通落子声；初始摆局、编辑和悔棋不发将军音。

BGM通过官方`game.ServerSignal('FCChessBGM')`发送四个有序参数：

| 参数序号（从0开始） | 类型 | 内容 |
|---|---|---|
| 0 | Int | 音乐库索引；0表示无BGM |
| 1 | Int | 音量0–100 |
| 2 | Float | 目录时长（秒），无BGM为0 |
| 3 | Bool | 是否启用：有曲目且音量大于0 |

标题、设置、选曲、自定义编辑使用标题音乐，其余对局/结果使用对局音乐。仅曲目或音量改变才发送；相同音乐跨页面不重新发送。脚本销毁发送停播请求。选择标题曲立即发请求，选择对局曲在进入对局时生效。

## 在奇域编辑器连接服务端节点

当前工具只能编辑2D+Lua工程，不能写入真实节点图。以下节点尚需在真实工程连接；模拟器存档的同名serverLogic规则只是接收探针，不是背景音乐节点。

1. 建立`FCChessBGM`服务端信号及对应四参数，监听客户端发来的信号；目标取发送该信号的玩家实体。
2. 在服务端按发送玩家记录当前曲目、播放/暂停状态。校验曲目属于`music-catalog.json`或0、音量在0–100；时长从服务端允许目录取得。
3. 启用=false时用「启动/暂停玩家背景音乐」暂停。不要把索引0传入「设置玩家背景音乐」。
4. 启用=true且曲目改变时调用「设置玩家背景音乐」：目标=发送玩家，背景音乐索引=选曲，开始=0、结束=目录秒数、音量=参数1、循环=true、循环间隔=0、播放速度=1、淡入淡出=true；随后恢复播放。
5. 启用=true且曲目相同时用「调整玩家背景音乐音量」传入参数1；若此前静音暂停则恢复播放。这样调音量不会从头重播。只有曲目变化才重新设置音乐。

若当前编辑器的音乐索引与抄录目录有差异，以当前音乐库为准同步目录。默认标题10167「杯中明月」、对局10029「追寻仙迹」。其他推荐：标题10161「桃符春叙」，对局10167「杯中明月」。推荐尚未经过真机听觉验收。

## 验证范围

模拟器可验证设置状态、Lua音效请求、信号参数与页面切换。`scripts/sync-game-save.mjs`生成接收探针，把四参数写入PlayerSelf的`FCChessMusicIndex/Volume/Seconds/Enabled`变量。信号PASS不代表真实BGM已播放。

真机接好节点后检查：标题/对局切曲、同曲跨页面连续播放、0%暂停后恢复、加减音量不重头、无BGM与音效开关互不影响、双方落子各响一次。当前无真机听觉验证。
